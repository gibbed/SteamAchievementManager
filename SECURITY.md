# Security Policy

## Supported versions

Only the [latest release](https://github.com/chavdar12/SteamAchievementManager/releases/latest) gets security fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/chavdar12/SteamAchievementManager/security/advisories/new) with the affected version, the impact and steps to reproduce.

You can expect a first reply within 7 days. If the report is confirmed, a fix is released and the advisory published with credit to you, unless you ask not to be named.
